### 1. 이슈 생성
```
[Type] 작업 내용
ex) [Feat] 회원가입 화면 구현
```
### 2. 브랜치 생성
```
Type/#IssueNumber-작업 내용
ex) Feat/#1-setting
 ```
### 3. 커밋 메시지
```
Type/#IssueNumber 작업 내용
ex) Feat/#1 로그인 화면 구현
```
### 4. PR 생성
```
[Type/#IssueNumber] 작업 내용
ex) [Feat/#1] 회원가입 및 로그인 화면 구현
```
### 5. Merge
```
Merge #IssueNumber -> develop
ex) Merge #1 -> develop

❗main 브랜치가 아닌 develop 브랜치로 merge❗
```

### Type
```
- [Feat] : 기능 구현
- [Fix] : 버그 수정
- [Mod] : 코드 및 파일 변경
- [Add] : 파일 추가
- [Delete] : 코드 및 파일 삭제
- [Refactor] : 코드 리팩토링
- [Docs] : 리드미 등의 문서 변경
- [Chore] : 환경 설정 등 기타 작업
```
